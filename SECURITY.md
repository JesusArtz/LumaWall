# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private
security advisory flow for this repository and include:

- the affected version or commit;
- a minimal proof of concept;
- expected and observed behavior; and
- any suggested mitigation.

LumaWall treats imported projects as untrusted data. It does not execute Windows
binaries, web wallpapers, or scripts found inside Wallpaper Engine projects.
