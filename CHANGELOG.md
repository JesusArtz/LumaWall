# Changelog

All notable changes to LumaWall will be documented here.

## [Unreleased]

### Added

- Native SwiftUI menu-bar application and wallpaper library.
- Hardware-accelerated video playback using AVFoundation.
- Native Metal rendering for supported Wallpaper Engine `scene.pkg` projects.
- Support for image scenes, masked water-wave effects, fog, and ember particles.
- Multi-display fill and fit modes, pause/resume controls, and Launch at Login.
- Professional app identity, project documentation, tests, and GitHub CI.
